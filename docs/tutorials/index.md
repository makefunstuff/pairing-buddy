# Tutorials

Short, task-shaped walkthroughs: each answers one "how do I…" in a few minutes, step by step, with the keys and
commands as they are, and links to the full page when you want more. Start with the first; the rest stand alone.

The pictures are the plugin and the daemon as shipped, in a clean Neovim with the ayu colorscheme, recorded from the
[capture tapes](../captures/). Only the models' words are scripted.
