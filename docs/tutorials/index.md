# Tutorials

Short, task-shaped walkthroughs: each answers one "how do I…" in a few minutes, step by step, with the keys and
commands as they are, and links to the full page when you want more. Start with the first; the rest stand alone.

The pictures are the plugin and the daemon as shipped, in a clean Neovim with the ayu colorscheme, recorded from the
[capture tapes](../captures/). Only the models' words are scripted.

- **[The first ten minutes](first-ten-minutes.md)**, 10 minutes: how do I install Pair, check it, and pair on a project?
- **[The chat pane and its keys](chat-pane.md)**, 4 minutes: how do I talk to Pair in the chat pane, and act on what it says?
- **[Roles and handing over](roles-and-hand-over.md)**, 4 minutes: how do I let Pair run commands, or hand it the keyboard?
- **[Tests on save](tests-on-save.md)**, 3 minutes: how do I have my tests run each time I save?
- **[Notes and the blank page](notes-and-blank-page.md)**, 5 minutes: how do I think in a note, or start from an empty folder?
- **[Asking for code: /gen here and /gen file](gen-here-and-file.md)**, 5 minutes: how do I ask Pair for code at my cursor, or for a new file?
- **[Trying a sample: /gen try and /keep](gen-try.md)**, 3 minutes: how do I try a sample before it goes in my project?
- **[A scaffold: /gen scaffold](gen-scaffold.md)**, 4 minutes: how do I get many files and their wiring at once?
- **[The board: hand a task over, review it back](board.md)**, 6 minutes: how do I hand a big job to the board, and review it back?
- **[Several worktrees](worktrees.md)**, 3 minutes: how do I work on two things in one repository at once?
- **[Voice](voice.md)**, 5 minutes: how do I ask Pair aloud?

The whole reference starts at [How it works](../how-it-works.md); every key is in the
[Neovim plugin reference](../neovim-plugin.md#keys) and every command in [Commands](../cli.md).
