# The video: a person in the second chair

A three-minute tour of pairing-buddy: the problem, the person in the second chair, the two models, then the three
moments in Neovim (it stops the wrong turn, it runs what you'd skip, the visible hand-over), the three roles, install
in two commands, and the keys to remember. It plays in the [README](../../README.md) and on the
[website](https://makefunstuff.github.io/pairing-buddy/#tutorial).

The video is a [HyperFrames](https://hyperframes.heygen.com) composition: `index.html` is generated by `build.mjs`
from its scene list, over real captures of the shipped plugin.

## What is real

The captures in `clips/` are VHS recordings of this checkout: the Neovim plugin, the daemon, its triggers, the
Watcher's gate, the test runs on save and on the unsaved buffer (`go test -json`, `go test -overlay`) and their
results all run for real, on the small Go project in `capture/hookd/`. Only the two models' words are scripted
(`capture/harness.mjs`), so every take says the same thing. The install capture runs the real
`npm install -g github:makefunstuff/pairing-buddy` and `pair setup` in an empty sandbox home.

## Make it again

Node.js 22+, FFmpeg, Go, Neovim 0.11+, VHS 0.11 with ttyd, and an OpenRouter key in `/tmp/openrouter.key` (or
`$OPENROUTER_KEY_FILE`) for the voice, the music and the word timings. The key is read at run time and never printed.

```sh
capture/run.sh                 # clips/moments.mp4 and clips/install.mp4 (or name one tape)
node tts.mjs [scene ...]       # audio/<scene>.mp3 from narration.json (existing files are kept unless named)
node words.mjs                 # words.json: when each word of the script is said, for the captions
node music.mjs                 # audio/music.mp3, the bed under the voice
node build.mjs                 # index.html, captions.vtt and frames/
npx hyperframes@0.8.205 render . --quality delivery --no-browser-gpu --output renders/tutorial.mp4
```

`build.mjs` holds the scenes: their titles, which stretch of a capture each one plays and how fast, where the camera
zooms, the callouts (`marks`), the keys shown on screen, and the before/after cards. Times are seconds into a scene,
or a word of the narration. Change the script in `narration.json`, then run `tts.mjs` for that scene, `words.mjs`
and `build.mjs`.

## Keeping it public

Every capture runs as a user whose home is a scratch folder under `/tmp`, with its own socket, so no personal path,
host or model name can show, and the running pairing-buddy service is never touched: `capture/run.sh` gives the
daemon a socket in that folder, and `capture/systemctl` stands in for `systemctl --user` during `pair setup`.
Before a new video is published, OCR its frames and check them and the file's metadata for usernames, home paths,
hosts, IP addresses, ports and model names.

Fonts: Inter and JetBrains Mono (`fonts/`, SIL Open Font License). The colorscheme of the captures is ayu
(`capture/colors/ayu.vim`, MIT). The voice is ElevenLabs v4 and the music Google Lyria 3, both through OpenRouter.
